# PortfoTrack
portfolio tracking app.

## Quick Start

```bash
# Install in development mode
uv pip install -e .

# Start the web server (default: http://127.0.0.1:5000)
python -m portfotrack

# Or use the installed command
portfotrack

# Custom host and port
portfotrack --host 0.0.0.0 --port 8080
```
